Deutscher Satzbau & Wortstellung

Verstehen Sie die Grundstruktur deutscher Sätze: die goldene V2-Regel, Inversion an Position 1, Nebensätze mit Verb am Ende und die TeKaMoLo-Regel.

1. Hauptsatz: Die V2-Regel (Verbposition 2)

Goldene Regel: Verb = Position 2

In deutschen Aussagesätzen steht das konjugierte Verb IMMER an Position 2. Position 1 kann durch das Subjekt, eine Zeitangabe, einen Ort oder ein Objekt belegt sein. Position 1 zählt als EIN grammatikalisches Element (nicht unbedingt ein einzelnes Wort!).

Position 1 (Subject) Ich
Position 2 (Verb) kaufe
Middle (Object) heute einen Apfel
End (Satzklammer) .

2. Inversion an Position 1 (Subjekt-Verb-Tausch)

Inversion: Subjekt rückt auf Position 3

Wenn ein anderes Element als das Subjekt an Position 1 steht (z. B. eine Zeitangabe, ein Ort oder eine Präpositionalphrase), BLEIBT das Verb an Position 2, und das Subjekt rückt sofort auf Position 3.

Position 1 (Time) Heute
Position 2 (Verb) kaufe
Position 3 (Subject) ich
Middle (Object) einen Apfel

3. Nebensatz: Die Verb-am-Ende-Regel

Unterordnende Konjunktion → Verb am Ende

Unterordnende Konjunktionen (z. B. weil, dass, obwohl, wenn, als, da) schieben das konjugierte Verb ganz an das Ende des Satzes.

Conjunction ... weil
Subject ich
Object Hunger
Clause End (Verb) habe.

4. TeKaMoLo-Regel (Adverbiale Reihenfolge)

Temporal → Kausal → Modal → Lokal
